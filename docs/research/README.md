## How to read the facts

- A date in brackets, such as (2026-02-19), is the daily note the fact comes from.
- Commit counts are `git` counts across all branches on 2026-11-14. The largest
  ones were re-checked by hand.
- "Stated" facts are written in a note or a repo. Anything worked out from them is
  marked "inferred".
- When a result is not written down anywhere, the text says "outcome not
  recorded". Those are the places where the site copy needs Timofey's input.
- The notes hold no client testimonials. Any quote on the site has to be asked for.

## Rules for this folder

This repository is public on GitHub. These files therefore leave out rates,
invoices, disputes, credentials, private people's names and client-internal
figures, even where the notes have them. Client and product names are included,
but none of them is cleared for the site yet; see
[05-before-publishing.md](05-before-publishing.md) before pushing this branch.
